# Analysis Folder Structure

This folder keeps the final analysis reports and files that can be reviewed before deletion.

- `error_sample_analysis/`: final notebooks for V1 metric/error analysis and V1/V2 comparison.
- `redundant_files_to_delete/`: duplicated or unnecessary intermediate files moved here for review before deletion.

V2 model code, training instructions, requirements, and outputs are stored in `../model/model_v2/`.
